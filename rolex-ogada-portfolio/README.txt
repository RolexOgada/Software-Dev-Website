Rolex Ogada — Portfolio Website
================================
Files:
  index.html      – the full website (single page, all sections)
  portfolio.css   – all styling / design system
  assets/         – portrait image

How to use:
  1. Unzip the folder.
  2. Double-click index.html to open it in any browser.
  3. To publish, upload all files (keep the folder structure) to any static
     host: Netlify, Vercel, GitHub Pages, cPanel, Firebase Hosting, etc.

Edit your details (name, apps, skills, experience, contact) directly in
index.html. Colors and fonts live at the top of portfolio.css under :root.
